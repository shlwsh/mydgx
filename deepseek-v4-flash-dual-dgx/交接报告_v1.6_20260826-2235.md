## 7. 关键排障经验（累计）

1. ghcr 下载：per-connection 限速 + curl 续传 bug → 串行整层下载（18MB/s）
2. OCI → docker load 需转 docker-archive
3. compose restart 不重读 env，需 down+up
4. NIM/vLLM 不能共存（UMA 121GB），NIM 须 --restart=no
5. LiteLLM 镜像源不可用（daocloud 不在白名单）→ 改用 venv pip 安装（清华源）
6. PEP 668 限制 → 用 venv 而非 --user
7. 本机 Python 访问 DGX 走系统代理绕路（11s），用 --noproxy 直连；opencode 直连不受影响
8. NGC 封锁、缓存权限、8000 端口、Clash pkill 恢复（见 v1.3）
