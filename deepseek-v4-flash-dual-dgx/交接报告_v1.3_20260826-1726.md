下载方式（关键突破）：

- 走本机代理 `127.0.0.1:7890`（出口 18.180.248.63）

- 进度日志：`...\vllm-oci\progress.log`（每 30s 一条）

**网络排障结论（重要经验）**：
1. **per-connection 限速**：单连接 ~2.3MB/s，8 连接 ~10.5MB/s，但 **>16 并发会触发代理连接上限导致全线崩溃**
2. **curl 续传 bug**：`-C -` 续传在该 CDN 下会卡死（chunk 重试 600 次不动）；改为**失败后整个 8MB range 从头重下**后，1.46GB 层 74 秒完成
3. 分块大小：8MB 最优（48MB 会卡、5MB 偏小）
4. 本机代理（7890）优于两台 DGX 的代理（Node 0/1 均 <200KB/s）
5. ghcr blob 存于 pkg-containers.githubusercontent.com CDN；国内镜像源（daocloud/1ms/xuanyuan）无此镜像

## 6. 关键排障经验
1. NGC 封锁（451）：manifest 走非中国代理；权重 xfiles 直连（NO_PROXY）
2. manifest 抖动崩溃循环：NIM_MANIFEST_DOWNLOAD_MAX_RETRY_COUNT=300
3. 缓存权限：容器 uid 1000(nvs)，目录须属 1000:1000
4. 8000 端口：Portainer 已重建去掉 8000 映射；勿再占用
5. Clash 失效：sudo pkill verge-mihomo 自动重启恢复
6. Docker daemon：nvidia runtime + proxy drop-in（NO_PROXY 含 ghcr.io/CDN）
7. **ghcr 下载**：per-connection 限速、禁续传、8MB 分块、8 并发最优（见 §4）
