## 6. ⚠️ 重要已知问题

### >32K prompt 触发 CUDA 崩溃（P0）
```
CUDA error at sparse_mla_sm120_prefill.cu:67: operation not permitted
Fatal Python error: Aborted → scheduler_0 crashed (exit -6) → 容器自动重启(~8-10min)
```
- 40K 必崩、24K 安全；Case D(64K) 当前不可用
- 缓解：restart 自动恢复 + healthcheck timer 兜底
- 待办：Phase D 用 `--context-length` canary 规避/确认阈值；跟踪 flashinfer sparse_mla 修复
- **使用建议：单次请求 prompt 控制在 ~24K token 以内**

### 其他注意
1. manifest 必须走代理（NGC 中国区封锁 451）；权重 xfiles 直连（NO_PROXY）
2. `NO_PROXY` 勿含 `api.ngc.nvidia.com`
3. NIM 容器 uid 1000(nvs)，缓存目录须属 1000:1000
4. Portainer 已重建去掉 8000 映射（9000/9443 保留）；重装 Portainer 时勿映射 8000
5. Clash 失效时：`sudo pkill verge-mihomo`（自动重启即恢复）
6. Node 0 曾发生整机无响应（SSH banner 超时但 ICMP/TCP 通），物理检查后恢复；原因未定位，healthcheck 可辅助监控
