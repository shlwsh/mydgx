### 3.4 静态地址配置（持久化）

两机均通过 NetworkManager 档案 `yunshu_WN-Office`（renderer netplan）设为静态，NM 变更自动写回 `/etc/netplan/90-NM-*.yaml`，重启自动恢复：

```bash
# 工作站（172.19.50.70）
sudo nmcli connection modify yunshu_WN-Office ipv4.method manual \
  ipv4.addresses 172.19.50.70/22 ipv4.gateway 172.19.51.254 \
  ipv4.dns "172.16.0.14,172.17.1.14"
# Node1（172.19.49.159）
sudo nmcli connection modify yunshu_WN-Office ipv4.method manual \
  ipv4.addresses 172.19.49.159/22 ipv4.gateway 172.19.51.254 \
  ipv4.dns "172.16.0.14,172.17.1.14"
```

- 持久化文件：工作站 `/etc/netplan/90-NM-c57ac383-….yaml`；Node1 `/etc/netplan/90-NM-ed101346-….yaml`。
- 生成的 NM keyfile：`[ipv4] method=manual / address1=<ip>/22,172.19.51.254 / dns=172.16.0.14;172.17.1.14;`。
- 回退：`ipv4.method` 改回 `auto` 并 `netplan apply`。

|---|---|---|---|---|
| **4000** | LiteLLM HTTP 网关 | 工作站 | `0.0.0.0` | 客户端主入口（推荐）|

> vLLM `:18090` 由 `vllm-port-lockdown.service` 用 iptables 收敛为仅 `127.0.0.1` 可达：
> `ACCEPT 127.0.0.1 → REJECT 其它`，禁止绕过 LiteLLM 直连。
